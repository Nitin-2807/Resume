## 🔥 Featured Projects

### 🧠 [Repix — AI-Powered Codebase Assistant](https://github.com/Nitin-2807/Repix)

**Python · FastAPI · Gemini · ChromaDB · React · PostgreSQL**

- Built an end-to-end **RAG application** that allows developers to ask natural-language questions about GitHub repositories.
- Engineered a repository ingestion pipeline to **clone repositories, parse files, chunk code, generate embeddings, and index them in ChromaDB**.
- Used **Sentence Transformers (all-MiniLM-L6-v2)** for semantic code retrieval.
- Optimized retrieval and prompting to reduce irrelevant context and keep responses grounded in the actual codebase.
- Developed REST APIs using **FastAPI and Pydantic**, with **PostgreSQL, SQLAlchemy, Alembic, and JWT authentication**.
- Built a responsive **React + Vite chat interface** for repository-aware conversations.

---

### 🌿 [Crop Disease Detection using AI](https://github.com/Nitin-2807/Crop-Disease-Detection)

**TensorFlow · CNN · Grad-CAM · Flask · SQLite**

- Built a custom **CNN using SeparableConv2D layers** to classify **15 crop-disease classes** from 128×128 leaf images.
- Achieved **79.97% accuracy** on the PlantVillage dataset.
- Developed the complete **image preprocessing, training, and evaluation pipeline**.
- Deployed the trained model through a **Flask web application** backed by SQLite.
- Integrated **Grad-CAM explainability** to visualize image regions influencing model predictions.
- Evaluated model behaviour on PlantDoc field images to study the impact of **background, lighting, and image conditions**.
- Combined **deep learning, computer vision, and explainable AI** for practical agricultural applications.
